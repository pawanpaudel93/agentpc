MCP server · Apple Silicon

A real computer for your agent, ready in a second

agentpc runs Windows, Ubuntu and Arch Linux ARM desktop VMs on your Mac and hands them to AI agents over MCP. The agent clicks, types, runs commands and takes screenshots, then resets the VM to a clean install in seconds.

Free and open source (MIT). Apple Silicon Mac, M1 or later. The installer adds QEMU and registers the MCP server with the agents it finds.

What it does

A single Rust binary that runs VMs with QEMU on Apple's hypervisor and serves them to agents over MCP.

Instant VMs
New VMs resume from a snapshot of a running desktop: about 1 s for Ubuntu and Arch, 4 s for Windows. Resetting a VM takes just as long.
Checkpoints
Save a running VM's disk and memory before a risky step, then return to that exact state in seconds.
Real desktops
Windows 11 (ARM), and Ubuntu or Arch Linux ARM with XFCE, each with a desktop-control server (cua-driver) that agents drive with clicks and keystrokes.
One MCP server
Agents create, drive, screenshot and delete VMs on their own. Works with any MCP client; agentpc mcp-install sets up the popular ones.
Shell and screen
PowerShell or bash over SSH. Screenshots come straight from the hypervisor in about 40 ms, even while a guest is booting or hung.
Files and ports
Copy files and folders between your Mac and a VM, and reach a server running inside a VM from your Mac.
Watch along
Every VM has a browser viewer, so you can watch what the agent is doing, live.
Local and private
Everything runs on your Mac and listens on 127.0.0.1 only. Offline VMs can't reach the internet or your Mac.

How an agent works in a VM

The same loop a person uses: look at the screen, act, look again to check the result.

  1. Look

    A hypervisor screenshot, or the UI tree with numbered elements.

    take_screenshotget_window_state

  2. Act

    Click, type and launch apps, or run a shell command when that's quicker.

    use_desktop_toolrun_command

  3. Verify, then reset

    Check the result, save a checkpoint, or reset to a clean install for the next run.

    checkpoint_vmreset_vm

Restart Claude Desktop after registering. agentpc mcp-uninstall removes it again.

/plugin marketplace add pawanpaudel93/agentpc
/plugin install agentpc@agentpc

Bundles the MCP server with a skill that teaches Claude when and how to use the VMs. Install the agentpc binary first.

{
  "mcpServers": {
    "agentpc": { "command": "agentpc", "args": ["mcp"] }
  }
}

One stdio server handles every VM. See the MCP docs for the tools.

Windows and Linux desktops, any version

Every VM is a copy-on-write clone of a read-only image, so it starts from a clean install and costs only a few MB.

ubuntu · ubuntu-22.04 · ubuntu-x86apps · arch · arch-x86apps

Ubuntu and Arch Linux ARM

XFCE on X11 on both, and both images download on first use. Ubuntu comes with Google Chrome for the browser tools (~1.2 GB download); arch comes with Chromium and pacman (and builds locally, ~6 min, only if the download fails). ubuntu-x86apps and arch-x86apps also run x86_64 Linux programs and amd64 containers, through FEX.

$ agentpc create ubuntu
~1 sto a new VM
4 GBRAM per VM
bashover SSH

windows · windows-11-24h2 · windows-11-23h2

Windows 11 ARM

Built once on your Mac from Microsoft's official ISO, since Windows images can't be redistributed. Includes Edge, and x64 apps run through Windows' Prism emulation.

$ agentpc image build windows  # once, ~12 min
$ agentpc create windows
~4 sto a new VM
8 GBRAM per VM
PowerShellover SSH
